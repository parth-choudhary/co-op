## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|-----------|
| Commit secrets to docker-compose.yml | The original Phase 1 stanza had inline placeholder secrets; replacing them with real ones in-place would publish them to GitHub | blocking | Use `${VAR}` interpolation everywhere; real values live in `.env` (gitignored under `.env*`). Verify with `git diff` before commit that no real secret strings appear. |
| Reuse upstream service names verbatim | Langfuse's published compose names its postgres simply `postgres` — clashes with our `db` and `synapse-db` if you copy verbatim | advisory | Prefix all langfuse services with `langfuse-` |
| Bind langfuse-web to port 3000 | Conflicts with the Next.js dev server | advisory | Map to `3001:3000` |
| Skip the worker container | langfuse-worker is required in v3 (background queue jobs); web alone won't process traces | blocking | Always bring up worker alongside web |
| Forget MinIO bucket bootstrap | Upstream's compose uses `entrypoint: sh / command: -c 'mkdir -p /data/langfuse && minio server …'` — without that, the bucket is missing on first start and event uploads fail silently | blocking | Copy the entrypoint verbatim |
| Set ENCRYPTION_KEY to anything other than 32-byte hex | Langfuse rejects malformed keys at startup | blocking | Use `openssl rand -hex 32` (yields exactly 64 hex chars) |
